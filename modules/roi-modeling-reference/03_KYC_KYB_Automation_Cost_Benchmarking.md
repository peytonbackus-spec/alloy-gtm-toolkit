# KYC/KYB Automation & Cost Benchmarking Matrix

## Cost Per Review Benchmarks
* **Manual Document Verification:** $12.50 – $18.00 per manual review (labor + vendor costs).
* **Automated Decisioning API Routing:** $0.45 – $1.20 per verification pass.
* **Target Automation Rates:**
  * Fast-Growth Fintechs: >92% auto-approval rate.
  * Commercial Banks: >80% auto-approval rate (due to complex business KYC/KYB structures).
